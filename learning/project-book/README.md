# DataGuard Project Learning Guide

This is a beginner-friendly, illustrated guide to the DataGuard CSV data-quality auditor. The guide explains what DataGuard does, how it works, and how to use it effectively.

## How to Use This Guide

1. **Read the Overview** - Understand what DataGuard solves and why it matters
2. **Explore the Architecture** - See how the system is structured
3. **Follow the Repository Tour** - Learn where files are located and their purposes
4. **Learn to Run It** - Set up and execute DataGuard commands
5. **Trace the Execution Journey** - Follow the complete data processing flow
6. **Understand Data Flow** - See how input becomes output
7. **Walk Through Modules** - Detailed explanations of each component
8. **Study Core Algorithms** - Deep dive into the main algorithms
9. **Review Testing Practices** - Learn what tests verify and how to run them
10. **Review Outputs** - Understand what reports are generated and how to interpret them
11. **Study Failure Scenarios** - Learn about common errors and how to debug them
12. **Complete the Exercises** - Practice with hands-on activities

## Directory Structure

The guide is organized into 15 main sections, each with detailed explanations, code examples, and diagrams.

## Rendering Requirements

- This HTML file works offline with no external dependencies
- Mermaid diagrams require network access to load the Mermaid library (CDN)
- If network access is unavailable, Mermaid diagrams will not render - fallback descriptions are provided in the captions
- All diagrams are also available as SVG files in the assets directory
